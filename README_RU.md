# OmniCam

[English](README.md) | **[Русский](README_RU.md)**

Превратите любой смартфон (iOS / Android) в высокопроизводительную беспроводную веб-камеру для Linux.  
**Без установки приложений на телефон. Только чистое видео. Интерактивное управление с ПК.**

OmniCam создаёт виртуальное устройство веб-камеры (`/dev/video0`) в Linux и передаёт видеопоток из браузера смартфона по WebRTC через локальный Wi-Fi с минимальной задержкой.

---

## Основные возможности

* **Утилита для терминала:** Запуск командой `omnicam` из любой папки.
* **Управление с клавиатуры ПК:** Переключение разрешения (`720`, `1080`), частоты кадров (`30`, `60`) и камер (`f` / `flip`) прямо из терминала во время стрима.
* **Поддержка двух языков (EN / RU):** Английский по умолчанию, переключение на русский одной кнопкой в веб-интерфейсе или параметром `--lang ru`.
* **Правильные пропорции (Aspect-Fit):** Честный широкоформатный 16:9 в горизонтальном положении и центрированное изображение с полями (pillarbox) в вертикальном. Без растяжений и искажений.
* **Честная диагностика:** Отображение реального разрешения захвата с телефона и выходного разрешения виртуальной камеры в реальном времени.
* **Чистый жизненный цикл:** Автоматическая загрузка модуля ядра `v4l2loopback` при старте и выгрузка при выходе. Никаких фантомных устройств в системе.
* **Без приложений на телефоне:** Работает в Safari (iOS) и Chrome (Android) через встроенный WebRTC. Достаточно отсканировать QR-код.
* **Только видео:** Не создаёт виртуальных аудиокарт и не засоряет аудиомикшер PulseAudio / PipeWire.
* **Минимальная задержка (~30-50 мс):** Прямая передача через локальную сеть по аппаратно-ускоренному WebRTC.

## Установка

### Вариант 1: Установка одной командой через cURL (Рекомендуется)

Автоматически проверяет и устанавливает системные пакеты (`v4l2loopback-dkms`), изолированное окружение и регистрирует глобальную команду `omnicam`:

```bash
curl -fsSL https://raw.githubusercontent.com/andrewbohachov/omnicam/main/install.sh | bash
```

### Вариант 2: Готовый deb-пакет для Debian / Ubuntu (.deb)

Скачайте готовый `.deb` пакет и установите через APT (все зависимости ядра и `v4l2loopback-dkms` установятся автоматически):

```bash
sudo apt install ./omnicam_0.1.0_all.deb
```

### Вариант 3: Ручная установка из исходников (Git / pip)

```bash
# 1. Установка системных зависимостей (Debian / Ubuntu / Mint)
sudo apt update
sudo apt install -y v4l2loopback-dkms v4l2loopback-utils libgl1 python3-pip python3-venv

# 2. Клонирование репозитория и установка пакета
git clone https://github.com/andrewbohachov/omnicam.git
cd omnicam
pip install -e .

# 3. Глобальный симлинк
sudo ln -sf $(which omnicam) /usr/local/bin/omnicam
```

## Быстрый запуск

Запустите в терминале:
```bash
omnicam
```

1. Наведите камеру телефона на QR-код в терминале.
2. Откройте ссылку в браузере и нажмите **"START STREAM"** (или **"НАЧАТЬ СТРИМ"**).
3. В Discord, OBS Studio, Telegram или Zoom выберите камеру **"OmniCam"**.

---

## Интерактивные команды в терминале

Во время стрима вводите команды в строку `omnicam > `:

| Команда | Описание |
| :--- | :--- |
| `720` / `1080` | Смена разрешения на лету |
| `30` / `60` | Изменение целевого FPS |
| `f` или `flip` | Переключение между фронтальной и основной камерой |
| `t` или `torch` | Включение / выключение фонарика (при поддержке устройством) |
| `s` или `status` | Показать статус потока, текущее разрешение и FPS |
| `lang en` / `lang ru` | Переключение языка интерфейса |
| `h` или `help` | Справка по командам |
| `q` или `quit` | Завершение работы и корректное удаление виртуального устройства |

## Параметры запуска

```
omnicam [ПАРАМЕТРЫ]

Параметры:
  -r, --res RES        Выходное разрешение: 1080 или 720 (по умолчанию: 1080)
  --lang {en,ru}       Язык интерфейса (по умолчанию: en)
  -p, --port PORT      Порт HTTPS сервера (по умолчанию: 8443)
  -d, --device DEVICE  Целевое V4L2 устройство (по умолчанию: /dev/video0)
  -l, --label LABEL    Имя камеры в приложениях (по умолчанию: OmniCam)
  --ip IP              Ручное указание локального IP адреса
  --keep-device        Не выгружать модуль v4l2loopback при выходе
  -h, --help           Показать справку
```

### Примеры:
```bash
# Стандартный запуск (1080p, английский язык)
omnicam

# Запуск в 720p для экономии полосы Wi-Fi
omnicam -r 720

# Запуск с русским языком консоли
omnicam --lang ru

# Запуск с пользовательским именем камеры
omnicam -l "Studio Cam"
```
